# japanese-tech-writing

[English](README.md)

日本語の技術文書・書籍原稿の文章規範。規範を定めるskillで、引数を取らず、単体ではファイルを出力しない。agentが日本語で章、草稿、記事、解説文を書く、または推敲するときに読み込み、その規則に従う。

日本語を新しく書くときの基準であり、[`exhtml`](../../docs/exhtml/README_ja.md)と[`exmd`](../../docs/exmd/README_ja.md)は文章の規範としてこれに従う。調べ物ではなく読み物として通読させたい文章には、これに加えて[`cognitive-rhythm-writing`](../cognitive-rhythm-writing/README_ja.md)を使う。既にあるAI臭い文章を直すには[`stop-ai-slop-jp`](../stop-ai-slop-jp/README_ja.md)を使う。

## 使い方

SKILL.mdのdescriptionにあるとおり、日本語で技術書の章、草稿、記事、解説文を書くとき、または推敲・リライトするときに使う。決まったトリガー文言はない。

## 動作

次の領域について規則を定める。

- 整形: 一文一行、コード・ログはコードブロック、補足は脚注、用語は初出の定義時に太字(以後の言及は「」)。日本語の地の文と見出しでダッシュ(emダッシュ、horizontal bar)と中黒(・)を使わない。見出しは単一の自然な句にする。
- 段落と論証の構成(パラグラフライティング): 一段落一主題で、論理的な接続を明示する。
- 論証の厳密さ: 断定的な因果、別物の一括り、回収されない前方参照など、ツッコミどころを除去する。
- 読み手の負荷の管理、視点と語り、演出の抑制。
- LLMっぽい空句の禁止: 予告と総括(「本章では〜を扱う」)、「正面から」系、空虚な形容と動詞、接続の連打、根拠のない緩和と称賛。
- 冗長の排除、原文の表記言語を保った具体的な見出し、読者への誠実さ(例が作為的に見えうることを隠さない、確認していないことを確認したように書かない)。

手順の詳細は[SKILL.md](SKILL.md)を参照。
