# yomiyasu-lite

## 概要

推敲の対象はlintが警告した箇所だけにする。警告のない文は、読みにくく見えても書き換えない。
直すときは意味を保つことを最優先にし、保てない言い換えしか思いつかなければ原文を残す。

## 手順

1. 原文がファイルでなければ、`mktemp -d` で作った一時ディレクトリに `原文.md` として保存する。
2. lintを実行する。文書の種類 (pr、incident、mail、minutes、manual、slides、essay、formal、promo、paperなど) が分かれば `--doc-type` を付ける。

   ```bash
   python3 <このskillのdirectory>/scripts/yomiyasu_lint.py 原文.md [--doc-type 種類]
   ```

3. 候補を1件ずつ判断する。警告文の「ただし〜なら残してかまいません」の条件に当たれば残す。
4. 直す箇所では、次の5点を原文と同じに保つ。
   - 何を主張しているか (「AではなくB」のAを消すと主張が変わるなら残す)
   - 言い切り・推量・伝聞の強さ
   - 数値・固有名詞・日時・条件
   - 誰が何をするか
   - 原文にない情報 (原因、主体、効果、手順) を足さない
5. 最終稿を原文と同じディレクトリに `<拡張子を除いた原文の名前>.yomiyasu.md` (例: `draft.md` なら `draft.yomiyasu.md`) として保存し、そのファイルにlintを再実行する。warnが残っていれば1回だけ見直し、それでも残すものは理由を書く。
   原文は書き換えない。ユーザーが原文の更新を頼んだときだけ、最終稿で原文を上書きする。

## 出力

次の形式で返して終了する。commit、push、外部への投稿はしない。

```markdown
### 書き直した本文

(保存先: 最終稿のパス)

(本文。見出しと箇条書きの構造は保つ)

### 変えたところ

- 元 → 後 (理由)。最大5点

### 残した警告

- ルールID: 箇所 (残した理由)。なければ「なし」

### 書き手に確かめたい点

- 意味が確定できず直さなかった箇所。なければこの見出しごと出さない
```
