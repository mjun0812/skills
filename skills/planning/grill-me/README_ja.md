# grill-me

[English](README.md)

計画や設計について、意思決定のあらゆる分岐点が解消されるまでユーザーへの質問を繰り返す。設計の分岐(設計ツリー)を順に辿り、決定事項の依存関係を一つずつ解決する。「幅」より「深さ」を優先し、新たな洞察が得られなくなるまで一つのテーマを掘り下げてから次へ進む。終了時には回答履歴を提示する。

agentが質問せずに自分で決めてほしい場合は[`grill-self`](../grill-self/README_ja.md)を使う。機械学習の実験計画には[`experiment-plan`](../experiment-plan/README_ja.md)を使う。

## 使い方

- "計画を詰めて"
- "計画を改善して"
- "設計を厳しく問い詰めて"
- SKILL.mdのdescriptionにあるとおり、計画の改善・詳細化・最適化を望む場合にも使う。

## 動作

- 質問は必ず一度に一つだけ行う。各質問にはagentの推奨回答と理由を付け、次のテンプレートに従う。

```text
### Q[番号]: [質問文]

1. [選択肢]
2. [選択肢]
3. ...

**推奨: [1/2/...]**
**理由:** ...
```

- 質問は`AskUserQuestion`などのユーザーに選択を促すツールで行う。
- 各質問の前にコードベースの関連箇所を調べ、調べれば分かることは聞かない。
- 論点を掘り尽くしたら終了を提案し、続行を求められた場合だけ続ける。
- 終了時に、質問と回答の対応が分かる形で回答履歴をまとめて提示する。

ファイルは書き込まない。

手順の詳細は[SKILL.md](SKILL.md)を参照。
