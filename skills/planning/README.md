# planning

Skills for turning a vague plan into decided, written-down choices. Two of them work through a design tree one decision at a time; the third produces a machine learning experiment plan.

## Which skill to use

| Situation                                                                | Skill                                          |
| ------------------------------------------------------------------------ | ---------------------------------------------- |
| Resolve every open decision by asking the user, one question at a time   | [`grill-me`](grill-me/README.md)               |
| Resolve every open decision by research and self-questioning, no prompts | [`grill-self`](grill-self/README.md)           |
| Write a machine learning experiment plan through an interview            | [`experiment-plan`](experiment-plan/README.md) |

`grill-me` and `grill-self` follow the same tree-walking approach (depth before breadth, investigate the codebase before deciding) and differ only in who decides.
