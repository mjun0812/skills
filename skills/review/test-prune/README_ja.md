# test-prune

[English](README.md)

コードベース内の全テストを精査し、削除・統合できるテストをリストアップする。判断基準は「削除すると、どんな現実的な不具合を見逃すか」で、テスト件数やカバレッジの維持自体は目的にしない。

## 使い方

- 「テストを減らして」
- 「不要なテストを洗い出して」
- 「テストを整理して」

```text
/test-prune
```

## 動作

- コードベース内の全テストを精査し、積極的に削除・統合できるテストをすべてリストアップする。
- 削る対象は、実装のコピー、モックの自己検証、型・ライブラリの保証の再確認、他テストとの重複、内部実装への過度な依存、過剰なケース分け。
- 念のためという理由ではテストを残さない。保証の価値を、実行時間・不安定さ・修正負担と比較する。
- テスト件数やカバレッジの維持自体を目的にしない。
