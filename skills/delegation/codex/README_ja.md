# codex

[English](README.md)

Codex CLIを非対話モードで呼び出し、相談への回答または委譲した作業の結果を得る。[`claude`](../claude/README_ja.md)のCodex版で、モードも同じ2つである。デフォルトはread-onlyの相談モードで、ユーザーが作業の実行を明示的に依頼したときだけ編集権限付きで実行する。

Claude Codeへ渡す場合は[`claude`](../claude/README_ja.md)を使う。別のagentが中断したsessionを引き継ぐ場合は[`resume-other-agent`](../resume-other-agent/README_ja.md)を使う。

## 使い方

`disable-model-invocation: true`のskillである。ユーザーがagentを名指ししたときだけ実行し、実行中のagentが自発的に呼ぶことはない。実行中のagent自身がCodexの場合も使わない。

- "Codexに聞いて"
- "Codexに相談して"
- "Codexにやらせて"
- "Codexに任せて"

## 動作

依頼の言い方でモードを決める。

| モード                 | 条件                                   | sandbox           |
| ---------------------- | -------------------------------------- | ----------------- |
| 相談モード(デフォルト) | 「聞いて」「相談して」「レビューして」 | `read-only`       |
| 委譲モード             | 「やらせて」「任せて」「作業させて」   | `workspace-write` |

判断に迷う場合は相談モード(read-only)を選ぶ。どちらのモードも`codex exec`を`-a never`と`--search` (web検索を有効化)付きで実行する。

- モデルとthinking effortは作業の大きさに応じて指定する。GPT-5.6 Family以外のモデルは指定しない。

| 作業                                             | モデル          | effort   |
| ------------------------------------------------ | --------------- | -------- |
| 軽い確認・定型的な相談・軽い修正                 | `gpt-5.6-luna`  | `medium` |
| 通常の作業・調査・レビュー・実装                 | `gpt-5.6-luna`  | `xhigh`  |
| 設計判断・曖昧な要件・複雑な調査・難しいデバッグ | `gpt-5.6-terra` | `high`   |
| 特に難しい判断・大規模な実装・深いレビュー       | `gpt-5.6-sol`   | `xhigh`  |

- 迷った場合は`gpt-5.6-luna`と`xhigh`を指定する。`xhigh`が失敗した場合は`high`に下げて再実行する。
- 相手はこの会話の文脈を知らないため、プロンプトは自己完結させる。背景と関連ファイルパスに加え、相談モードでは質問を、委譲モードでは成功条件を含める。
- 数分で終わらない見込みの作業は`run_in_background`で起動し、`BashOutput`で完了までポーリングする。
- 相談モード: 回答は第二意見として扱う。回答をそのまま転送せず、要点と根拠を整理し、呼び出し元の見解との一致点・相違点を添えて提示する。最終判断は呼び出し元のagentが行う。
- 委譲モード: `-a never`で承認を求めずに実行する。実行結果と変更箇所を提示し、呼び出し元のagentが差分を確認して必要なら追加修正する。
- `codex` CLIが未導入(`which codex`が失敗)、または認証やpermissionのエラーで実行できない場合は、直ちに中止してユーザーに伝える。
