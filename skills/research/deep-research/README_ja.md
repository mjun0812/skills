# deep-research

[English](README.md)

モデルの事前知識と徹底したweb検索を統合してテーマをdeep researchし、引用付きの調査メモを1つのMarkdownで作成する。メモはまず提示し、確認が取れた場合のみカレントディレクトリに保存する。

このSkillは調査とメモ作成だけを行う。メモの要約・整理・他ファイルへの統合は行わない。

## 使い方

- 「〜について調べてメモにして」
- 「deep researchして」

```text
/deep-research Rustのasync runtime比較
/deep-research --no-save WebGPUの普及状況
```

## 引数

| 引数        | 効果                                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `--no-save` | 保存の確認をせず、ファイルも作成しない。調査メモの本文を応答としてそのまま返す。他のskill・agent・`claude -p`から呼ぶときは必須。 |

## 動作

- スコープを確認する。調査方針が分かれるほど曖昧な場合のみ2〜3個質問する。テーマが与えられていなければ確認して終了する。
- テーマを3〜8個のサブ質問に分解し、それぞれを英語と日本語の両方で検索する。公式ドキュメント・論文・公式発表などの一次情報源を優先し、検索結果の一覧だけでなくページ本文まで読む。
- 執筆前に品質ゲートを確認する。目安は、情報源が10件以上・5ドメイン以上、各サブ質問に答えられる材料がある、本文の柱になる主張が情報源で裏付けられている、の3点。テーマが狭く情報源が構造的に少ない場合は、件数を稼がず、その旨を報告に含める。
- ドラフトの前に、欠落、反論、直近の変更を点検する。
- メモは結論を最初に書き、本文を論点ごとにまとめ、未解決事項を挙げ、末尾に本文の`[n]`と対応する番号付きの参照一覧を置く。情報源同士が食い違う場合は、どちらかに寄せず違いを書く。
- 文章は`references/`に同梱した`japanese-tech-writing`と`stop-ai-slop-jp`の写しに従う。単独でinstallしても動作する。
- `--no-save`が無い場合は、メモを提示し、保存するかを確認したうえで、カレントディレクトリに`YYYY-MM-DD_<slug>.md`として保存する。frontmatterは`title`、`created`、`updated`、`model`。有用な図は`images/`にダウンロードし、相対パスでリンクする。
- 保存後は`oxfmt`で整形し、引用番号と参照一覧の対応、画像リンク先の存在を確認する。
- 特定agentのtoolに依存しないため、Claude Code以外のcoding agentでも使える。

## 依存

- `oxfmt`(保存したメモの整形)
