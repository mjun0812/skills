# doc-sync

[English](README.md)

リポジトリ内のドキュメントを実際の実装と比較し、事実として古くなっている箇所を検出して更新する。対象はMarkdown、docstringとheaderコメント、OpenAPI/Swagger、設定ファイル例。文体や言い回しの好みは乖離として扱わない。

検出した全乖離を、確認なしで一括更新する。`--dry-run`を指定すると何も編集せず、乖離とbefore/afterのプレビューだけを報告する。

## 使い方

- 「ドキュメントを更新」
- 「READMEが古いので直して」

```text
/doc-sync
/doc-sync --dry-run
/doc-sync docs/api/
/doc-sync README.md --dry-run
```

## 引数

| 引数        | 効果                                                               |
| ----------- | ------------------------------------------------------------------ |
| `--dry-run` | ファイルを更新せず、乖離とbefore/afterのプレビューだけを報告する。 |
| `<path>`    | 対象のディレクトリまたはファイルに絞る。省略時はリポジトリ全体。   |
| `language`  | 更新時の文章言語。省略時は既存ドキュメントの言語を維持する。       |

## 動作

- 対象ドキュメントを探索し、パス・名前・シグネチャ・CLIフラグ・設定キー・バージョンなどの記述をコードと照合して、乖離をファイルとセクション単位で列挙する。
- 事実が誤っている箇所だけを最小限の範囲で更新する。既存の言語、見出しレベル、リストや表の形式、docstringのスタイルは維持する。
- 判断に迷う乖離は更新せずスキップし、最後にスキップ一覧として報告する。
- `node_modules/`, `.git/`, `dist/`, `build/`, `vendor/`, `.venv/`, `.mjun/` は常に除外する。`.mjun/`配下のspec・steering・実験計画は書き換えない。
- commitしない。
- zod-to-openapiなどで生成されるOpenAPIは更新を控え、ユーザーに通知する。大規模リポジトリやモノレポでは`<path>`で対象を絞る。
