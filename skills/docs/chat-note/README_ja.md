# chat-note

[English](README.md)

現在の会話で確立した内容を、事実・推論・未確認事項を区別したまま、日本語のMarkdown1ファイルへ書き出す。先頭に目次を置き、末尾に参考リンクを付けるので、あとから再検索なしに読み返せる。

外部情報は足さない。会話に無い題材の解説や、調査から始める依頼には[`exmd`](../exmd/README_ja.md)を使う。

## 使い方

- 「今の内容をメモにまとめて」
- 「ここまでの話をMarkdownにまとめて」

## 動作

- 最初に対象範囲を確定する。指定が無ければ会話全体を対象にする。
- 会話内の情報だけで書く。追加検索や外部情報での補完は、ユーザーが明示的に依頼したときだけ行う。
- 出力は1つのMarkdownファイル。frontmatter(`title`, `model`, `created`, `updated`)、先頭の目次、短い要約、自由記述の本文、参考リンクで構成する。
- 保存先はユーザーの指定に従う。指定が無ければカレントディレクトリに `YYYY-MM-DD-<slug>.md` として保存する。同名ファイルがあれば上書き前に確認する。
- 返答前に、目次が先頭にあること、単体で理解できること、結論が前半にあることを確認する。返答は何をまとめたかと保存結果だけで、本文は再掲しない。

手順の詳細は[SKILL.md](SKILL.md)を参照。
